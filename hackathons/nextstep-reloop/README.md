# ReLoop — Circular Electronics Companion

**NextStep Hacks 2026 · Earth Forward**

ReLoop is a privacy-first decision companion that helps a user choose a sensible next step for an electronic device: keep/repair, reuse/donate, targeted repair, or responsible recycling.

## What the prototype does
- Browser-only assessment; no account, serial number, photo, location, or identity data.
- Inputs: device type, approximate age, function, physical condition, battery/power condition, repair confidence, and second-life potential.
- Transparent rule-based Circularity Score and recommendation.
- Safety-first override when a battery/power concern is reported.
- Short action plan for each path.
- Illustrative indicators are clearly labelled and are not lifecycle-assessment, carbon-accounting, safety-certification, or professional-repair results.

## Run
```bash
npm start
```
Open `http://localhost:3000`.
