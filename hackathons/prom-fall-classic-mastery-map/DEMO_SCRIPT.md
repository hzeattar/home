# MasteryMap AI — 90-second demo script

**0:00–0:10 — Problem**
“Most quiz apps tell you whether you were right. MasteryMap AI answers a more useful question: what should you study next?”

**0:10–0:22 — Product**
“MasteryMap is an adaptive learning coach. It estimates mastery for Algorithms, Networking, Databases, and Probability, then chooses the next question based on where another answer would create the most learning value.”

**0:22–0:42 — Live answer**
Start a session. Point to the mastery map and AI Decision panel.
“Before I answer, the model predicts my chance of success and explains why this concept was selected.”
Answer the question correctly.
“Now the Bayesian Knowledge Tracing model updates that concept’s mastery probability using the evidence from my answer.”

**0:42–0:58 — Adaptation**
Answer the next question incorrectly.
“An incorrect answer is also useful evidence. The mastery estimate changes, and the recommender re-ranks the practice options instead of following a fixed question order.”

**0:58–1:12 — Explainable AI**
Show the AI Decision panel.
“The recommendation combines learning need, model uncertainty, spaced-practice urgency, difficulty fit, and novelty. The student sees those reasons rather than trusting a black box.”

**1:12–1:23 — Quick demo**
Run Quick Demo.
“This simulates several answers so you can watch the mastery map and predicted success adapt across concepts in seconds.”

**1:23–1:32 — Privacy + engineering**
“The entire model runs locally in the browser: no login, no paid API, and no learner data sent to a server. The probabilistic model also has deterministic Node tests.”

**1:32–1:38 — Close**
“MasteryMap AI: study what your brain needs next — and know why.”
